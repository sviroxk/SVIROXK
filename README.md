## Кейсы

В портфолио представлены концептуальные исследования. Они помечены как демонстрационные работы; вымышленные предприятия, продукты, мероприятия, услуги и макетные показатели не являются коммерческими клиентами или подтверждёнными результатами.

## Форма обращения

Production-сборка использует GitHub Actions Variables `VITE_CONTACT_ENDPOINT` и `VITE_CONTACT_EMAIL`. Сейчас переменные указывают AJAX-доставку FormSubmit на `winchestersdc79@gmail.com`. Поставщик может запросить подтверждение адреса при первом сообщении. Успех показывается только после успешного HTTP-ответа.

Форма использует honeypot и задержку отправки; эти меры не заменяют серверное ограничение частоты. Переменные `VITE_*` попадают в публичный браузерный файл, поэтому нельзя хранить в них секретные ключи. История заявок пока локальна в браузере; серверного кабинета или централизованной базы нет.

## Юридические документы

Страницы `/privacy` и `/terms` описывают фактический маршрут заявки, FormSubmit, локальную историю, договорный статус и права на материалы. Они остаются проектами до заполнения полей оператора, юрисдикции, почтового и юридического адреса владельцем и проверки применимым юристом.

## Разработка

- `npm ci` — установить зависимости.
- `npm run build` — проверить TypeScript и собрать production-версию.
- Workflow GitHub Actions публикует `dist/` в Pages при изменениях в ветке `main`.

Стек: React, TypeScript, Vite, React Router, Framer Motion и Lucide.
