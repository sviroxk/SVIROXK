# Студия SVIROXK

Независимая студия веб-дизайна и разработки цифровых продуктов. Интерфейс и материалы сайта на русском языке; портфолио состоит из концепций, а не заявленных коммерческих заказов.

## Сайт и публикация

- Сайт: [Открыть Студию SVIROXK](https://winchestersdc79-hub.github.io/SVIROXK/)
- Репозиторий: https://github.com/winchestersdc79-hub/SVIROXK
- GitHub Pages публикует production-сборку `dist/` через GitHub Actions при изменениях в `main`.
- Для страниц и ресурсов используется базовый путь `/SVIROXK/`.
- Файл Google Search Console: `/google1b98991cb98a846f.html`.

## Содержимое и возможности

- 25 концептуальных проектов с индивидуальными страницами-кейсами и сценами.
- Каталог из 27 стилей с отдельными графическими композициями, палитрами и русскими названиями.
- Фильтрация и поиск портфолио; фильтрация каталога стилей.
- Подбор стиля, сравнение и локальное избранное без регистрации.
- Конфигуратор предварительного брифа и передача выбранного стиля в форму заказа.
- Интерактивные демонстрации экранов кейсов с переключением страницы и размера устройства.
- Интерактивная восьмиэтапная временная шкала, FAQ, контакты, `/privacy` и `/terms`.
- Тёмное звёздное поле реагирует на курсор; учитывается `prefers-reduced-motion`.
- Адаптивная навигация и переходы по HashRouter для GitHub Pages.

Все вымышленные предприятия, продукты, мероприятия и сервисы обозначены как концепции. Демонстрационные макеты, данные и сценарии не являются запущенными системами.

## Форма и обработка обращений

Production-сборка использует GitHub Actions Variables `VITE_CONTACT_ENDPOINT` и `VITE_CONTACT_EMAIL`. Сейчас endpoint настроен на AJAX FormSubmit с получателем `winchestersdc79@gmail.com`; поставщик может запросить подтверждение адреса при первой доставке. Успех показывается только после успешного ответа endpoint.

Honeypot, минимальное время заполнения и тайм-аут — клиентские базовые меры; защита от прямых запросов и частотные ограничения зависят от сервиса доставки. Значения `VITE_*` входят в открытый JavaScript браузерной сборки: не помещайте туда секреты. Локальная история обращений хранится только в браузере посетителя; централизованной базы или клиентского кабинета нет.

## Юридические документы

`/privacy` и `/terms` описывают текущую передачу заявок в FormSubmit и локальную историю в `localStorage`. Документы остаются черновиками: поля оператора, юрисдикции, юридического контакта, адреса и срока хранения должен подтвердить владелец. Требуется проверка фактической обработки данных и юридическая проверка до публикации как окончательных документов.

## Проверки и снимки

- `npm ci` — установка зависимостей.
- `npm run build` — TypeScript и production-сборка.
- `npm run check:visuals` — соответствие проектов, стилей, графических сцен и услуг.
- `npm run test:e2e` — Playwright-проверки маршрутов, UI-сценариев и экранов 320×720, 360×800, 390×844, 768×1024, 1024×768, 1280×800, 1440×900 и 1920×1080.
- Скриншоты «до/после» находятся в `artifacts/screenshots/before/` и `artifacts/screenshots/after/`; дополнительные снимки исправлений — в `artifacts/screenshots/fixes/`.
