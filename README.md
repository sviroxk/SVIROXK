## Отправка обращений

Production-сборка получает GitHub Actions Variables `VITE_CONTACT_ENDPOINT` и `VITE_CONTACT_EMAIL`. Сейчас endpoint — FormSubmit AJAX для `winchestersdc79@gmail.com`; поставщик может запросить подтверждение email при первой доставке. Форма показывает подтверждение только при успешном HTTP-ответе endpoint.

Honeypot, минимальное время заполнения и тайм-аут — клиентские базовые меры; защита от прямых запросов и ограничение частоты зависят от настроек сервиса. `VITE_*` значения встраиваются в открытый клиентский JavaScript, поэтому сюда нельзя помещать секретные ключи. История заявок пока хранится локально в браузере; серверного кабинета или централизованной базы нет.

## Юридические документы

Страницы `/privacy` и `/terms` описывают текущий путь отправки, хранение, внешний FormSubmit и статус заявки относительно договора. Это черновые документы: владелец должен заполнить обозначенные поля оператора, адреса и юрисдикции, проверить поставщика и получить юридическую проверку перед тем, как считать их окончательными.

## Разработка и проверки

- `npm ci` — установка зависимостей.
- `npm run build` — проверка TypeScript и production-сборка.
- `npm audit --omit=dev --audit-level=high` — проверка уязвимостей production-зависимостей.
- GitHub Actions автоматически строит и публикует `dist/`.

Стек: React, TypeScript, Vite, React Router, Framer Motion и Lucide.
